# AutoMapper – Conditional Mapping

**Conditional Mapping** means a property is mapped **only when a specific condition is satisfied**.

Use `.Condition()` when you don't want AutoMapper to map a value under certain circumstances.

### Example

```csharp
public class Patient
{
    public string Name { get; set; }
    public int Age { get; set; }
}

public class PatientDto
{
    public string Name { get; set; }
    public int Age { get; set; }
}
```

Suppose we only want to map `Age` when it is greater than `0`:

```csharp
CreateMap<Patient, PatientDto>()
    .ForMember(
        dest => dest.Age,
        opt => opt.Condition(src => src.Age > 0)
    );
```

### Result

```text
Age = 25  → mapped ✅
Age = 0   → not mapped ❌
Age = -1  → not mapped ❌
```

### Common Use: Updating Existing Entities

Conditional mapping is especially useful for **partial updates**:

```csharp
CreateMap<UpdatePatientDto, Patient>()
    .ForMember(
        dest => dest.Name,
        opt => opt.Condition(src => !string.IsNullOrEmpty(src.Name))
    );
```

This prevents an empty `Name` from overwriting the existing value.

### Key Methods

| Method            | Purpose                                               |
| ----------------- | ----------------------------------------------------- |
| `.Condition()`    | Map only if condition is true                         |
| `.PreCondition()` | Check condition **before** resolving the source value |

**Interview point:**

> Conditional mapping controls whether AutoMapper should assign a property based on a runtime condition.
