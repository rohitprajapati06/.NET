# AutoMapper – Null Substitution

**Null Substitution** means providing a **default value when the source property is `null`**.

Use `.NullSubstitute()`.

### Example

```csharp
public class Patient
{
    public string Name { get; set; }
}

public class PatientDto
{
    public string Name { get; set; }
}
```

Configure:

```csharp
CreateMap<Patient, PatientDto>()
    .ForMember(
        dest => dest.Name,
        opt => opt.NullSubstitute("Unknown")
    );
```

### Result

```text
Patient.Name = "Rohit"
        ↓
PatientDto.Name = "Rohit"

Patient.Name = null
        ↓
PatientDto.Name = "Unknown"
```

### Complex Type Example

It can also be used with nested values:

```csharp
CreateMap<Patient, PatientDto>()
    .ForMember(
        dest => dest.City,
        opt => opt.NullSubstitute("Not Available")
    );
```

If the source value is `null`, `"Not Available"` is assigned.

### `NullSubstitute()` vs `Condition()`

| Feature            | Purpose                                      |
| ------------------ | -------------------------------------------- |
| `NullSubstitute()` | Replace `null` with a default value          |
| `Condition()`      | Decide whether the property should be mapped |

**Interview point:**

> `NullSubstitute()` provides a fallback value when the source member is `null`; it does not simply ignore the property.
