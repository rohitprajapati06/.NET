# AutoMapper – Ignore Property Mapping

**Ignore Property Mapping** means telling AutoMapper **not to map a specific property**.

Use `.Ignore()` when a destination property should not be populated from the source.

### Example

```csharp
public class Patient
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Password { get; set; }
}

public class PatientDto
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Password { get; set; }
}
```

If you don't want `Password` to be mapped:

```csharp
CreateMap<Patient, PatientDto>()
    .ForMember(
        dest => dest.Password,
        opt => opt.Ignore()
    );
```

So:

```text
Patient.Password
       ↓
      IGNORE ❌
       ↓
PatientDto.Password
```

### Common Use Cases

* Sensitive properties like `Password`
* Properties managed by the database
* Audit fields like `CreatedDate`
* Properties that should be calculated separately
* Fields that should not be updated during an API request

### For DTO → Entity

For example, don't allow the client to modify `Id`:

```csharp
CreateMap<UpdatePatientDto, Patient>()
    .ForMember(
        dest => dest.Id,
        opt => opt.Ignore()
    );
```

### Key Point

```csharp
.ForMember(dest => dest.Property, opt => opt.Ignore());
```

> **`Ignore()` tells AutoMapper to completely skip mapping that destination property.**
