# AutoMapper – Complex Type to Primitive Type

This means mapping a **complex/nested object** to a **primitive property** such as `string`, `int`, `decimal`, etc.

### Example

Entity:

```csharp
public class Patient
{
    public int Id { get; set; }
    public NameInfo Name { get; set; }
}

public class NameInfo
{
    public string FirstName { get; set; }
    public string LastName { get; set; }
}
```

DTO:

```csharp
public class PatientDto
{
    public int Id { get; set; }
    public string Name { get; set; }
}
```

Here:

```text
NameInfo (Complex Type)
        ↓
string Name (Primitive Type)
```

### AutoMapper Configuration

AutoMapper **cannot automatically determine** how to convert the whole `NameInfo` object into a `string`. You explicitly specify the source property:

```csharp
CreateMap<Patient, PatientDto>()
    .ForMember(
        dest => dest.Name,
        opt => opt.MapFrom(src => 
            $"{src.Name.FirstName} {src.Name.LastName}")
    );
```

Result:

```text
NameInfo
FirstName = "Rohit"
LastName  = "Prajapati"

        ↓ AutoMapper

Name = "Rohit Prajapati"
```

### Key Point

For **Complex → Primitive** mapping, use:

```csharp
.ForMember()
.MapFrom()
```

because AutoMapper needs to know **which value from the complex object should become the primitive value**.

**Interview point:**
`Patient.Name → PatientDto.Name` is not a normal property-to-property mapping because their types differ (`NameInfo → string`), so explicit mapping is required.
