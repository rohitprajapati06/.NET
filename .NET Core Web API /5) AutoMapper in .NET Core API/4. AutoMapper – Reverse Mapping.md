# AutoMapper – Reverse Mapping

**Reverse Mapping** allows you to configure mapping in both directions using a single `CreateMap()`.

### Without Reverse Mapping

```csharp
CreateMap<Patient, PatientDto>();
CreateMap<PatientDto, Patient>();
```

You need to define both mappings separately.

### With `ReverseMap()`

```csharp
CreateMap<Patient, PatientDto>()
    .ReverseMap();
```

This enables:

```text
Patient ────────> PatientDto
   ↑                 │
   └─────────────────┘
```

So both work:

```csharp
var dto = _mapper.Map<PatientDto>(patient);
```

and:

```csharp
var patient = _mapper.Map<Patient>(dto);
```

### When to use?

Useful when **both objects have matching properties** and you need mapping in both directions, e.g.:

```csharp
CreateMap<Patient, PatientDto>()
    .ReverseMap();
```

### Important

`ReverseMap()` is **not always appropriate**.

If the DTO contains properties that shouldn't update the entity, such as:

```text
Entity → DTO       ✅
DTO → Entity       ❌
```

then define the mapping separately instead of using `ReverseMap()`.

**Interview point:**

> `ReverseMap()` creates the reverse mapping automatically, reducing duplicate mapping configuration.
