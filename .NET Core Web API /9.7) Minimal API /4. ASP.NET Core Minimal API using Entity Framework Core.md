# ASP.NET Core Minimal API using Entity Framework Core

**Minimal API + Entity Framework Core** allows us to build lightweight REST APIs that directly interact with a database using EF Core.

A typical flow is:

```text
Client
   ↓
Minimal API Endpoint
   ↓
Entity Framework Core
   ↓
SQL Server
```

---

## 1. Create the Entity

For example, a `Product` entity:

```csharp
public class Product
{
    public int Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public decimal Price { get; set; }
}
```

---

## 2. Create DbContext

```csharp
public class AppDbContext : DbContext
{
    public AppDbContext(DbContextOptions<AppDbContext> options)
        : base(options)
    {
    }

    public DbSet<Product> Products { get; set; }
}
```

`DbContext` is responsible for communicating with the database.

---

## 3. Configure Connection String

In `appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=.;Database=ProductDb;Trusted_Connection=True;TrustServerCertificate=True"
  }
}
```

---

## 4. Register EF Core

In `Program.cs`:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlServer(
        builder.Configuration.GetConnectionString("DefaultConnection")));

var app = builder.Build();
```

Now `AppDbContext` can be injected into Minimal API endpoints.

---

# 5. GET All Products

```csharp
app.MapGet("/api/products", async (
    AppDbContext context) =>
{
    var products = await context.Products
        .ToListAsync();

    return Results.Ok(products);
});
```

Request:

```text
GET /api/products
```

The flow is:

```text
GET Request
    ↓
MapGet()
    ↓
AppDbContext
    ↓
Products DbSet
    ↓
SQL Query
    ↓
JSON Response
```

---

# 6. GET Product By ID

```csharp
app.MapGet("/api/products/{id}", async (
    int id,
    AppDbContext context) =>
{
    var product = await context.Products
        .FindAsync(id);

    if (product == null)
        return Results.NotFound();

    return Results.Ok(product);
});
```

Request:

```text
GET /api/products/10
```

---

# 7. POST Product

```csharp
app.MapPost("/api/products", async (
    Product product,
    AppDbContext context) =>
{
    context.Products.Add(product);

    await context.SaveChangesAsync();

    return Results.Created(
        $"/api/products/{product.Id}",
        product);
});
```

Request body:

```json
{
    "name": "Laptop",
    "price": 50000
}
```

`SaveChangesAsync()` generates the appropriate SQL `INSERT`.

---

# 8. PUT Product

```csharp
app.MapPut("/api/products/{id}", async (
    int id,
    Product input,
    AppDbContext context) =>
{
    var product = await context.Products
        .FindAsync(id);

    if (product == null)
        return Results.NotFound();

    product.Name = input.Name;
    product.Price = input.Price;

    await context.SaveChangesAsync();

    return Results.NoContent();
});
```

---

# 9. DELETE Product

```csharp
app.MapDelete("/api/products/{id}", async (
    int id,
    AppDbContext context) =>
{
    var product = await context.Products
        .FindAsync(id);

    if (product == null)
        return Results.NotFound();

    context.Products.Remove(product);

    await context.SaveChangesAsync();

    return Results.NoContent();
});
```

---

# 10. Complete Example

A simple `Program.cs` can look like:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlServer(
        builder.Configuration.GetConnectionString("DefaultConnection")));

var app = builder.Build();

app.MapGet("/api/products", async (
    AppDbContext context) =>
{
    var products = await context.Products.ToListAsync();

    return Results.Ok(products);
});

app.MapGet("/api/products/{id}", async (
    int id,
    AppDbContext context) =>
{
    var product = await context.Products.FindAsync(id);

    return product is null
        ? Results.NotFound()
        : Results.Ok(product);
});

app.MapPost("/api/products", async (
    Product product,
    AppDbContext context) =>
{
    context.Products.Add(product);
    await context.SaveChangesAsync();

    return Results.Created(
        $"/api/products/{product.Id}",
        product);
});

app.MapDelete("/api/products/{id}", async (
    int id,
    AppDbContext context) =>
{
    var product = await context.Products.FindAsync(id);

    if (product is null)
        return Results.NotFound();

    context.Products.Remove(product);
    await context.SaveChangesAsync();

    return Results.NoContent();
});

app.Run();
```

## 11. Using `AsNoTracking()`

For read-only queries, you can use:

```csharp
var products = await context.Products
    .AsNoTracking()
    .ToListAsync();
```

This tells EF Core that the entities don't need to be tracked for updates.

It is useful for **read-only APIs**.

---

## 12. Using CancellationToken

For production APIs:

```csharp
app.MapGet("/api/products", async (
    AppDbContext context,
    CancellationToken cancellationToken) =>
{
    var products = await context.Products
        .AsNoTracking()
        .ToListAsync(cancellationToken);

    return Results.Ok(products);
});
```

This allows the database operation to be cancelled when the request is cancelled.

---

# 13. Migrations

After configuring EF Core, create a migration:

```bash
dotnet ef migrations add InitialCreate
```

Then apply it:

```bash
dotnet ef database update
```

EF Core creates the database/table based on your entity and `DbContext`.

---

## Recommended Structure

For a small API:

```text
Minimal API
│
├── Program.cs
├── Models
│   └── Product.cs
├── Data
│   └── AppDbContext.cs
└── appsettings.json
```

For a larger application, avoid putting all business logic inside `Program.cs`. Use:

```text
Endpoint
   ↓
Service
   ↓
Repository / EF Core
   ↓
Database
```

---

## Interview Answer

> **We can use Entity Framework Core with Minimal APIs by registering the `DbContext` through dependency injection and injecting it directly into endpoint handlers. We use asynchronous EF Core methods such as `ToListAsync()`, `FindAsync()`, and `SaveChangesAsync()` for database operations. For read-only queries, we can use `AsNoTracking()`, and `CancellationToken` can be passed to database operations to support request cancellation.**
