# JWT Authentication in ASP.NET Core Web API

**JWT (JSON Web Token)** is a token-based authentication mechanism commonly used to secure ASP.NET Core Web APIs.

Instead of sending username/password with every request, the client **logs in once**, receives a JWT, and sends that token with subsequent requests.

### How JWT works

```text
Client
   ↓ Username + Password
API
   ↓ Validate credentials
JWT Token
   ↓
Client stores token
   ↓
Authorization: Bearer <token>
   ↓
API validates JWT
   ↓
Access granted
```

### 1. JWT Structure

A JWT has 3 parts:

```text
Header.Payload.Signature
```

Example:

```text
xxxxx.yyyyy.zzzzz
```

* **Header** → Algorithm and token type
* **Payload** → Claims such as UserId, Username, Role
* **Signature** → Verifies that the token wasn't modified

> JWT payload is **encoded, not encrypted**, so don't put passwords or sensitive secrets inside it.

### 2. Configure JWT Authentication

Install:

```text
Microsoft.AspNetCore.Authentication.JwtBearer
```

Then configure `Program.cs`:

```csharp
builder.Services.AddAuthentication("Bearer")
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,

            ValidIssuer = "MyApi",
            ValidAudience = "MyClient",

            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes("your-secret-key"))
        };
    });

builder.Services.AddAuthorization();
```

### 3. Configure Middleware

```csharp
app.UseAuthentication();
app.UseAuthorization();

app.MapControllers();
```

**Order matters:** `UseAuthentication()` must come before `UseAuthorization()`.

### 4. Protect an Endpoint

```csharp
[Authorize]
[HttpGet]
public IActionResult GetUsers()
{
    return Ok();
}
```

The client sends:

```http
Authorization: Bearer eyJhbGciOiJIUzI1Ni...
```

### Role-Based JWT Authorization

If the JWT contains a role claim:

```csharp
[Authorize(Roles = "Admin")]
[HttpDelete("{id}")]
public IActionResult DeleteUser(int id)
{
    return Ok();
}
```

Only users with the `Admin` role can access it.

### JWT vs Basic Authentication

| Basic Authentication                     | JWT                                |
| ---------------------------------------- | ---------------------------------- |
| Sends username/password repeatedly       | Sends token                        |
| Stateless                                | Stateless                          |
| Simple                                   | More flexible                      |
| Credentials must be protected with HTTPS | Token must be protected with HTTPS |
| Less suitable for modern APIs            | Common for modern APIs             |

**In short:** JWT provides **stateless, token-based authentication** where the server validates a signed token instead of requiring the user's credentials on every request.
