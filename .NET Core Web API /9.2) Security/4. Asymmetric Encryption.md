# Asymmetric Encryption in ASP.NET Core Web API

**Asymmetric encryption** uses two keys:

* 🔑 **Public Key** → used for encryption
* 🔐 **Private Key** → used for decryption

```text
Client
   │
   │ Encrypt using Public Key
   ↓
Encrypted Data
   │
   │ Decrypt using Private Key
   ↓
ASP.NET Core API
```

### 1. Generate RSA Keys

ASP.NET Core/.NET provides `RSA` for asymmetric encryption.

```csharp
using System.Security.Cryptography;

using var rsa = RSA.Create(2048);

string publicKey = Convert.ToBase64String(
    rsa.ExportRSAPublicKey());

string privateKey = Convert.ToBase64String(
    rsa.ExportRSAPrivateKey());
```

The **public key can be shared**, but the **private key must remain secret**.

### 2. Encrypt Using Public Key

```csharp
using var rsa = RSA.Create();

rsa.ImportRSAPublicKey(
    Convert.FromBase64String(publicKey),
    out _);

byte[] encrypted = rsa.Encrypt(
    Encoding.UTF8.GetBytes("Hello"),
    RSAEncryptionPadding.OaepSHA256);

string cipherText = Convert.ToBase64String(encrypted);
```

### 3. Decrypt Using Private Key

```csharp
using var rsa = RSA.Create();

rsa.ImportRSAPrivateKey(
    Convert.FromBase64String(privateKey),
    out _);

byte[] decrypted = rsa.Decrypt(
    Convert.FromBase64String(cipherText),
    RSAEncryptionPadding.OaepSHA256);

string plainText = Encoding.UTF8.GetString(decrypted);
```

### Where is it used?

* Secure exchange of sensitive information
* Digital signatures
* Certificate-based authentication
* Securely exchanging symmetric encryption keys

### RSA vs AES

| RSA (Asymmetric)         | AES (Symmetric)      |
| ------------------------ | -------------------- |
| Public + Private key     | One shared key       |
| Slower                   | Faster               |
| Good for small data/keys | Good for large data  |
| Key exchange/signatures  | Bulk data encryption |

**Important:** In real applications, don't encrypt large request bodies directly with RSA. A common approach is **hybrid encryption**: use RSA to protect/exchange an AES key, then use AES to encrypt the actual data.
