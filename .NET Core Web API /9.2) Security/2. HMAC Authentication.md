# HMAC Authentication in ASP.NET Core Web API

**HMAC (Hash-based Message Authentication Code)** is an authentication mechanism used to verify that a request **comes from a trusted client** and that the request **was not modified** in transit.

It uses a shared **Secret Key** to generate a signature.

### How it works

```text
Client
  ↓
Creates Signature using Secret Key
  ↓
HTTP Request + Signature
  ↓
ASP.NET Core API
  ↓
Recreates Signature using same Secret Key
  ↓
Compare Signatures
  ↓
Match → Allow request
No Match → 401 Unauthorized
```

### 1. Client generates HMAC

For example:

```csharp
string data = $"{httpMethod}{path}{timestamp}{body}";

using var hmac = new HMACSHA256(
    Encoding.UTF8.GetBytes(secretKey));

string signature = Convert.ToBase64String(
    hmac.ComputeHash(Encoding.UTF8.GetBytes(data)));
```

The client sends headers such as:

```http
X-Client-Id: client123
X-Timestamp: 1726220000
X-Signature: generated-signature
```

### 2. API validates the signature

Create custom authentication middleware/filter:

```csharp
using System.Security.Cryptography;
using System.Text;

public async Task InvokeAsync(HttpContext context)
{
    var clientId = context.Request.Headers["X-Client-Id"].ToString();
    var timestamp = context.Request.Headers["X-Timestamp"].ToString();
    var signature = context.Request.Headers["X-Signature"].ToString();

    // Get secret key for clientId from secure storage/database
    var secretKey = GetSecretKey(clientId);

    var data = $"{context.Request.Method}" +
               $"{context.Request.Path}" +
               $"{timestamp}";

    using var hmac = new HMACSHA256(
        Encoding.UTF8.GetBytes(secretKey));

    var hash = hmac.ComputeHash(
        Encoding.UTF8.GetBytes(data));

    var expectedSignature =
        Convert.ToBase64String(hash);

    if (!CryptographicOperations.FixedTimeEquals(
            Convert.FromBase64String(signature),
            Convert.FromBase64String(expectedSignature)))
    {
        context.Response.StatusCode = StatusCodes.Status401Unauthorized;
        return;
    }

    await _next(context);
}
```

### 3. Register Middleware

```csharp
app.UseMiddleware<HmacAuthenticationMiddleware>();
```

Place it **before your controllers/endpoints**.

### HMAC vs Password Hashing

| Password Hashing             | HMAC Authentication                  |
| ---------------------------- | ------------------------------------ |
| Used for storing passwords   | Used for authenticating API requests |
| One-way                      | Requires shared secret               |
| `PasswordHasher<TUser>`      | `HMACSHA256`                         |
| Password cannot be recovered | Both client and server know secret   |

**Key point:** HMAC does not replace password hashing. Use password hashing for user passwords and HMAC when you need **signed API requests between trusted systems/clients**.
