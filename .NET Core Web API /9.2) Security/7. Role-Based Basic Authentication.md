# Role-Based Basic Authentication in ASP.NET Core Web API

**Role-Based Basic Authentication** means the API first authenticates the user using **username/password**, then checks the user's **role** to determine whether they can access an endpoint.

```text
Request
  ↓
Basic Authentication
  ↓
Validate Username + Password
  ↓
Load User Role
  ↓
Authorization
  ↓
Admin → Admin endpoints
User  → User endpoints
```

### 1. Create User Model

```csharp
public class User
{
    public string Username { get; set; }
    public string PasswordHash { get; set; }
    public string Role { get; set; }
}
```

Example database data:

```text
Username    PasswordHash    Role
admin       ********        Admin
john        ********        User
```

### 2. Basic Authentication Middleware

After validating the credentials, create a `ClaimsPrincipal` containing the user's role:

```csharp
var claims = new[]
{
    new Claim(ClaimTypes.Name, user.Username),
    new Claim(ClaimTypes.Role, user.Role)
};

var identity = new ClaimsIdentity(
    claims,
    "Basic");

context.User = new ClaimsPrincipal(identity);

await _next(context);
```

The important part is:

```csharp
new Claim(ClaimTypes.Role, user.Role)
```

This makes the role available to ASP.NET Core authorization.

### 3. Configure Authorization

```csharp
builder.Services.AddAuthorization();
```

And in the pipeline:

```csharp
app.UseMiddleware<BasicAuthMiddleware>();

app.UseAuthorization();

app.MapControllers();
```

### 4. Restrict Endpoint by Role

```csharp
[Authorize(Roles = "Admin")]
[HttpDelete("{id}")]
public IActionResult DeleteUser(int id)
{
    return Ok("User deleted");
}
```

Only users with the **Admin** role can access this endpoint.

For multiple roles:

```csharp
[Authorize(Roles = "Admin,Manager")]
```

This allows either **Admin OR Manager**.

### Authentication vs Role Authorization

```text
Authorization: Basic <credentials>
              ↓
        Authentication
              ↓
       Username verified
              ↓
         Role identified
              ↓
       [Authorize(Roles="Admin")]
              ↓
       Access granted/denied
```

### Important

Basic Authentication itself **doesn't provide roles**. You add role information after authenticating the user, typically as a **claim**, and ASP.NET Core's `[Authorize(Roles = "...")]` performs the authorization check.

For production, use **HTTPS** and secure password hashing (e.g., `PasswordHasher<TUser>`); don't compare or store plaintext passwords.
