# How to Store Password in Hash Format in ASP.NET Core Web API

**Never store passwords as plain text.** Store a **one-way hash** of the password instead.

### 1. Using `PasswordHasher<TUser>` — Recommended

ASP.NET Core provides `PasswordHasher<TUser>` through ASP.NET Core Identity.

```csharp
using Microsoft.AspNetCore.Identity;

public class UserService
{
    private readonly PasswordHasher<User> _passwordHasher = new();

    public string HashPassword(User user, string password)
    {
        return _passwordHasher.HashPassword(user, password);
    }

    public bool VerifyPassword(User user, string password, string hashedPassword)
    {
        var result = _passwordHasher.VerifyHashedPassword(
            user,
            hashedPassword,
            password);

        return result == PasswordVerificationResult.Success;
    }
}
```

### 2. Store the Hash in Database

Instead of:

```text
Password: MyPassword123
```

Store something like:

```text
PasswordHash: AQAAAAIAAYagAAAAE...
```

The hash includes the information needed to verify the password, so **you don't need to store a separate salt** when using `PasswordHasher`.

### 3. During Registration

```csharp
user.PasswordHash = _passwordHasher.HashPassword(user, request.Password);

await _context.Users.AddAsync(user);
await _context.SaveChangesAsync();
```

### 4. During Login

```csharp
var result = _passwordHasher.VerifyHashedPassword(
    user,
    user.PasswordHash,
    request.Password);

if (result == PasswordVerificationResult.Success)
{
    // Login successful
}
else
{
    // Invalid password
}
```

### Important

* ❌ Don't store plain-text passwords.
* ❌ Don't use simple SHA256/SHA512 for password storage.
* ❌ Don't decrypt passwords—passwords should be **one-way hashed**.
* ✅ Use `PasswordHasher<TUser>` or ASP.NET Core Identity.
* ✅ Store only the resulting `PasswordHash` in the database.
* ✅ Use HTTPS so the password is protected while being transmitted.
