# Basic Authentication in ASP.NET Core Web API

**Basic Authentication** sends the username and password in the HTTP `Authorization` header.

```http
Authorization: Basic base64(username:password)
```

### How it works

```text
Client
  ↓
Username + Password
  ↓ Base64 Encoding
Authorization: Basic xxxx
  ↓
ASP.NET Core API
  ↓
Decode → Validate credentials
  ↓
200 OK / 401 Unauthorized
```

### 1. Create Basic Authentication Middleware

```csharp
public class BasicAuthMiddleware
{
    private readonly RequestDelegate _next;

    public BasicAuthMiddleware(RequestDelegate next)
    {
        _next = next;
    }

    public async Task InvokeAsync(HttpContext context)
    {
        if (!context.Request.Headers.TryGetValue(
                "Authorization", out var authHeader))
        {
            context.Response.StatusCode = 401;
            return;
        }

        var auth = authHeader.ToString();

        if (!auth.StartsWith("Basic "))
        {
            context.Response.StatusCode = 401;
            return;
        }

        var encodedCredentials = auth["Basic ".Length..].Trim();
        var credentials = Encoding.UTF8.GetString(
            Convert.FromBase64String(encodedCredentials));

        var parts = credentials.Split(':', 2);

        var username = parts[0];
        var password = parts[1];

        // Validate username/password from database
        if (username != "admin" || password != "password123")
        {
            context.Response.StatusCode = 401;
            return;
        }

        await _next(context);
    }
}
```

### 2. Register Middleware

In `Program.cs`:

```csharp
app.UseMiddleware<BasicAuthMiddleware>();

app.MapControllers();
```

### 3. Client Request

```http
GET /api/users
Authorization: Basic YWRtaW46cGFzc3dvcmQxMjM=
```

The Base64 value represents:

```text
admin:password123
```

### Important Security Points

* **Base64 is encoding, NOT encryption.**
* Always use **HTTPS** with Basic Authentication.
* Never hard-code real credentials.
* Validate passwords against **secure password hashes**, not plaintext.
* Basic Authentication sends credentials with every request, so **JWT/OAuth2 is generally preferred for modern APIs**.

**Interview point:** Basic Authentication is simple, but because credentials are repeatedly transmitted, it should only be used over **HTTPS** and is generally less suitable than token-based authentication for modern APIs.
