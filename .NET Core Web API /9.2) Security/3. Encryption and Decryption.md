# Encryption and Decryption in ASP.NET Core Web API

**Encryption** converts readable data (**Plaintext**) into unreadable data (**Ciphertext**) using a key. **Decryption** converts it back to the original data.

```text
Plaintext
   ↓ Encryption + Key
Ciphertext
   ↓ Decryption + Key
Plaintext
```

### 1. Symmetric Encryption

The **same key** is used for encryption and decryption.

A common choice in .NET is **AES**.

```csharp
using System.Security.Cryptography;
using System.Text;

public class EncryptionService
{
    private readonly byte[] _key;

    public EncryptionService(IConfiguration config)
    {
        _key = Convert.FromBase64String(config["EncryptionKey"]!);
    }

    public string Encrypt(string plainText)
    {
        using var aes = Aes.Create();
        aes.Key = _key;
        aes.GenerateIV();

        using var encryptor = aes.CreateEncryptor();

        var plainBytes = Encoding.UTF8.GetBytes(plainText);
        var cipherBytes = encryptor.TransformFinalBlock(
            plainBytes, 0, plainBytes.Length);

        return Convert.ToBase64String(
            aes.IV.Concat(cipherBytes).ToArray());
    }
}
```

The key should be stored securely, **not hard-coded**:

```json
{
  "EncryptionKey": "..."
}
```

For production, use **Azure Key Vault, environment variables, or another secret-management system**.

### 2. Decryption

```csharp
public string Decrypt(string encryptedText)
{
    var data = Convert.FromBase64String(encryptedText);

    using var aes = Aes.Create();
    aes.Key = _key;

    var iv = data[..16];
    var cipherText = data[16..];

    aes.IV = iv;

    using var decryptor = aes.CreateDecryptor();

    var plainBytes = decryptor.TransformFinalBlock(
        cipherText, 0, cipherText.Length);

    return Encoding.UTF8.GetString(plainBytes);
}
```

### Encryption vs Hashing

| Encryption                | Hashing                             |
| ------------------------- | ----------------------------------- |
| Reversible                | One-way                             |
| Has encryption/decryption | No decryption                       |
| Used for sensitive data   | Used mainly for passwords/integrity |
| AES                       | PasswordHasher / Argon2 / bcrypt    |

**Important:** Don't encrypt passwords. Passwords should be **hashed**, preferably using ASP.NET Core Identity's `PasswordHasher<TUser>`. Encryption is appropriate when you genuinely need to recover the original value.
