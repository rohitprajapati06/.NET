# Unit Testing Controllers in ASP.NET Core Web API

Controller unit testing verifies whether your **controller behaves correctly for different service/handler results**.

For your level, the key things to test are:

* HTTP status codes
* Returned data
* `NotFound()`
* `BadRequest()`
* `Ok()`
* `CreatedAtAction()`
* Dependency interaction

We'll use **xUnit + Moq**.

---

## 1. Controller Architecture

A typical API looks like:

```text
HTTP Request
     ↓
Controller
     ↓
Service
     ↓
Repository
     ↓
Database
```

During a controller **unit test**, we don't test the service or database.

```text
Controller
     ↓
Mock Service
     ↓
Fake Result
```

The service is replaced with a mock.

---

# 2. Example Controller

Suppose we have:

```csharp
[ApiController]
[Route("api/[controller]")]
public class DoctorsController : ControllerBase
{
    private readonly IDoctorService _service;

    public DoctorsController(IDoctorService service)
    {
        _service = service;
    }

    [HttpGet("{id}")]
    public async Task<IActionResult> GetDoctor(Guid id)
    {
        var doctor = await _service.GetDoctorByIdAsync(id);

        if (doctor == null)
            return NotFound();

        return Ok(doctor);
    }
}
```

Service interface:

```csharp
public interface IDoctorService
{
    Task<Doctor?> GetDoctorByIdAsync(Guid id);
}
```

---

# 3. Create Controller Test

```csharp
public class DoctorsControllerTests
{
    private readonly Mock<IDoctorService> _serviceMock;
    private readonly DoctorsController _controller;

    public DoctorsControllerTests()
    {
        _serviceMock = new Mock<IDoctorService>();

        _controller = new DoctorsController(
            _serviceMock.Object);
    }
}
```

Now:

```text
DoctorsController
       ↓
Mock<IDoctorService>
```

No real service or database is involved.

---

# 4. Test Successful Request

We want:

```text
GET /api/doctors/{id}

        ↓

Doctor exists

        ↓

200 OK
```

Test:

```csharp
[Fact]
public async Task GetDoctor_WhenDoctorExists_ReturnsOk()
{
    // Arrange
    var doctorId = Guid.NewGuid();

    var doctor = new Doctor
    {
        Id = doctorId,
        Name = "Dr. John",
        Specialization = "Cardiology"
    };

    _serviceMock
        .Setup(x => x.GetDoctorByIdAsync(doctorId))
        .ReturnsAsync(doctor);

    // Act
    var result = await _controller.GetDoctor(doctorId);

    // Assert
    var okResult = Assert.IsType<OkObjectResult>(result);

    var returnedDoctor =
        Assert.IsType<Doctor>(okResult.Value);

    Assert.Equal(doctorId, returnedDoctor.Id);
    Assert.Equal("Dr. John", returnedDoctor.Name);
}
```

---

# 5. Understand the Test

### Arrange

Create test data:

```csharp
var doctor = new Doctor
{
    Id = doctorId,
    Name = "Dr. John"
};
```

Configure the mock:

```csharp
_serviceMock
    .Setup(x => x.GetDoctorByIdAsync(doctorId))
    .ReturnsAsync(doctor);
```

Meaning:

> When the controller asks the service for this doctor, return this fake doctor.

---

### Act

Call the controller directly:

```csharp
var result = await _controller.GetDoctor(doctorId);
```

Notice that we're **not sending a real HTTP request**.

---

### Assert

Check the HTTP result:

```csharp
var okResult = Assert.IsType<OkObjectResult>(result);
```

Then check the response body:

```csharp
var returnedDoctor =
    Assert.IsType<Doctor>(okResult.Value);
```

Finally:

```csharp
Assert.Equal(doctorId, returnedDoctor.Id);
```

# 6. Test NotFound

Now suppose the doctor doesn't exist.

Expected:

```text
Service → null
          ↓
Controller
          ↓
404 Not Found
```

Test:

```csharp
[Fact]
public async Task GetDoctor_WhenDoctorDoesNotExist_ReturnsNotFound()
{
    // Arrange
    var doctorId = Guid.NewGuid();

    _serviceMock
        .Setup(x => x.GetDoctorByIdAsync(doctorId))
        .ReturnsAsync((Doctor?)null);

    // Act
    var result = await _controller.GetDoctor(doctorId);

    // Assert
    Assert.IsType<NotFoundResult>(result);
}
```

This is a very common controller test.

---

# 7. Verify Service Was Called

You can also verify that the controller called the service correctly.

```csharp
_serviceMock.Verify(
    x => x.GetDoctorByIdAsync(doctorId),
    Times.Once);
```

This means:

> `GetDoctorByIdAsync()` must have been called exactly once.

# 8. Testing POST

Suppose the controller has:

```csharp
[HttpPost]
public async Task<IActionResult> CreateDoctor(CreateDoctorRequest request)
{
    var id = await _service.CreateDoctorAsync(request);

    return CreatedAtAction(
        nameof(GetDoctor),
        new { id },
        null);
}
```

Test:

```csharp
[Fact]
public async Task CreateDoctor_WhenSuccessful_ReturnsCreated()
{
    // Arrange
    var request = new CreateDoctorRequest
    {
        Name = "Dr. Smith",
        Specialization = "Neurology"
    };

    var doctorId = Guid.NewGuid();

    _serviceMock
        .Setup(x => x.CreateDoctorAsync(request))
        .ReturnsAsync(doctorId);

    // Act
    var result = await _controller.CreateDoctor(request);

    // Assert
    var createdResult =
        Assert.IsType<CreatedAtActionResult>(result);

    Assert.Equal(nameof(DoctorsController.GetDoctor),
                 createdResult.ActionName);
}
```

---

# 9. Testing BadRequest

Suppose:

```csharp
[HttpPost]
public async Task<IActionResult> CreateDoctor(CreateDoctorRequest request)
{
    if (request == null)
        return BadRequest();

    var id = await _service.CreateDoctorAsync(request);

    return CreatedAtAction(
        nameof(GetDoctor),
        new { id },
        null);
}
```

Test:

```csharp
[Fact]
public async Task CreateDoctor_WhenRequestIsNull_ReturnsBadRequest()
{
    // Arrange
    CreateDoctorRequest request = null;

    // Act
    var result = await _controller.CreateDoctor(request);

    // Assert
    Assert.IsType<BadRequestResult>(result);
}
```

# 10. Important Controller Results to Test

| Controller behavior | What to assert          |
| ------------------- | ----------------------- |
| `Ok(data)`          | `OkObjectResult`        |
| `Ok()`              | `OkResult`              |
| `NotFound()`        | `NotFoundResult`        |
| `BadRequest()`      | `BadRequestResult`      |
| `CreatedAtAction()` | `CreatedAtActionResult` |
| `NoContent()`       | `NoContentResult`       |
| `Unauthorized()`    | `UnauthorizedResult`    |
| `Forbid()`          | `ForbidResult`          |

# 11. Controller vs Service Unit Testing

This distinction is important for interviews.

| Controller Test           | Service Test                  |
| ------------------------- | ----------------------------- |
| Tests HTTP/API behavior   | Tests business logic          |
| Checks status codes       | Checks business rules         |
| Checks response objects   | Checks calculations/decisions |
| Mocks service             | Mocks repository              |
| `Ok()`, `NotFound()` etc. | Business conditions           |
| Usually very lightweight  | Usually contains more logic   |

Example:

```text
Controller Test
      ↓
Mock Service
      ↓
Verify:
200 / 404 / 400
```

Whereas:

```text
Service Test
      ↓
Mock Repository
      ↓
Verify:
Business Logic
```

## Key Interview Answer

> **"For controller unit testing, I mock the service layer using Moq and directly invoke the controller action. I verify the returned HTTP result such as 200, 400, 404, or 201, along with the response data. I also use `Verify()` to ensure the controller calls the appropriate service method with the expected parameters."**

### Testing flow to remember

```text
             CONTROLLER UNIT TEST
                     │
                     ▼
              Mock Service
                     │
                     ▼
              Call Action
                     │
                     ▼
             Check HTTP Result
                     │
          ┌──────────┼──────────┐
          ▼          ▼          ▼
        200 OK    404 NotFound 400 BadRequest
```
