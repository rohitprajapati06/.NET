# Fluent API Validation in ASP.NET Core Web API

**Fluent API Validation** usually refers to using **FluentValidation**, a popular library for defining validation rules separately from your model.

Instead of using attributes like `[Required]`, `[StringLength]`, etc., you define rules using a **fluent syntax**.

### 1. Install FluentValidation

```bash
dotnet add package FluentValidation.AspNetCore
```

### 2. Create Model

```csharp
public class Employee
{
    public string Name { get; set; }
    public string Email { get; set; }
    public int Age { get; set; }
}
```

### 3. Create Validator

```csharp
using FluentValidation;

public class EmployeeValidator : AbstractValidator<Employee>
{
    public EmployeeValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty()
            .MaximumLength(50);

        RuleFor(x => x.Email)
            .NotEmpty()
            .EmailAddress();

        RuleFor(x => x.Age)
            .InclusiveBetween(18, 60);
    }
}
```

### 4. Register Validator

```csharp
builder.Services.AddValidatorsFromAssemblyContaining<EmployeeValidator>();
```

### 5. Use in Controller

```csharp
[HttpPost]
public IActionResult Create(Employee employee)
{
    // Validation is performed before processing
    return Ok(employee);
}
```

### Why use FluentValidation?

| Data Annotation               | FluentValidation                 |
| ----------------------------- | -------------------------------- |
| Rules are inside model        | Rules are separated from model   |
| Good for simple validation    | Excellent for complex validation |
| Less flexible                 | Highly flexible                  |
| Attribute-based               | Fluent/programmatic syntax       |
| Harder to reuse complex rules | Rules can be reused              |

### Example of conditional validation

```csharp
RuleFor(x => x.Email)
    .NotEmpty()
    .When(x => x.Age >= 18);
```

**In short:** FluentValidation keeps your **DTO/model clean** and puts validation logic into dedicated validator classes, making complex validation easier to maintain and test.
