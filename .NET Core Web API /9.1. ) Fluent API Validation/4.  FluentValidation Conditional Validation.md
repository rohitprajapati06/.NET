# FluentValidation Conditional Validation in ASP.NET Core Web API

**Conditional validation** means applying a validation rule **only when a specific condition is true**.

FluentValidation provides mainly **`When()`** and **`Unless()`** for this.

### 1. Using `When()`

```csharp
public class EmployeeValidator : AbstractValidator<Employee>
{
    public EmployeeValidator()
    {
        RuleFor(x => x.Email)
            .NotEmpty()
            .EmailAddress()
            .When(x => x.IsEmailRequired);
    }
}
```

Here, `Email` is validated **only when `IsEmailRequired` is `true`**.

---

### 2. Using `Unless()`

`Unless()` is the opposite of `When()`.

```csharp
RuleFor(x => x.Email)
    .NotEmpty()
    .Unless(x => x.IsEmailOptional);
```

The rule runs **unless `IsEmailOptional` is true**.

---

### 3. Conditional Validation for Multiple Rules

```csharp
When(x => x.EmployeeType == "Permanent", () =>
{
    RuleFor(x => x.Salary)
        .GreaterThan(0);

    RuleFor(x => x.JoiningDate)
        .NotEmpty();
});
```

Both rules execute only for **Permanent employees**.

---

### 4. Example

```csharp
public class Employee
{
    public string EmployeeType { get; set; }
    public decimal Salary { get; set; }
}
```

```csharp
RuleFor(x => x.Salary)
    .GreaterThan(0)
    .When(x => x.EmployeeType == "Permanent");
```

**Result:**

* `EmployeeType = "Permanent"` → Salary must be greater than `0`.
* `EmployeeType = "Contract"` → Salary rule is skipped.

### `When()` vs `Unless()`

| Method              | Meaning                                    |
| ------------------- | ------------------------------------------ |
| `When(condition)`   | Run validation when condition is **true**  |
| `Unless(condition)` | Run validation when condition is **false** |

**Key point:** Conditional validation is useful when a field is required or has specific rules **only for certain types, statuses, roles, or business conditions**.
