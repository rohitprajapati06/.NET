# Authentication Server using ASP.NET Core Web API

In an **SSO architecture**, an **Authentication Server** is the central service responsible for authenticating users and issuing tokens that multiple applications can trust.

### Architecture

```text
                 Authentication Server
                    (Identity Provider)
                           │
                      User Login
                           │
                      Access Token
                           │
          ┌────────────────┼────────────────┐
          ↓                ↓                ↓
       Web App        Mobile App       Admin App
          │                │                │
          └────────────────┼────────────────┘
                           ↓
                    ASP.NET Core APIs
```

### How it works

1. User accesses an application.
2. Application redirects the user to the **Authentication Server**.
3. User logs in **once**.
4. Authentication Server authenticates the user.
5. It issues an **authorization code/access token**.
6. The application uses the token to call protected APIs.
7. Other applications can use the existing SSO session, so the user doesn't need to log in again.

### Common Technologies

* **OpenID Connect (OIDC)** → Authentication
* **OAuth 2.0** → Authorization
* **JWT** → Common access-token format
* **Microsoft Entra ID / Auth0 / Okta / Keycloak** → Common Identity Providers

### Important distinction

```text
Authentication Server
        ↓
Authenticates user + issues tokens

Resource Server (ASP.NET Core API)
        ↓
Validates token + authorizes requests
```

**Interview answer:**

> An Authentication Server in an SSO architecture is a centralized Identity Provider that authenticates users and issues tokens. Applications redirect users to it for login, and after successful authentication, they receive tokens to access protected APIs. This enables the same authenticated session to be used across multiple applications without requiring separate logins.
