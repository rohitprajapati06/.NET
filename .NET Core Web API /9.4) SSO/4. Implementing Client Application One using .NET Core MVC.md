# Implementing Client Application One using ASP.NET Core MVC

In an **SSO architecture**, Client Application One is an ASP.NET Core MVC application that uses the **Authentication Server / Identity Provider** for login.

The MVC application **does not directly validate usernames and passwords**. It redirects the user to the Identity Provider.

### Architecture

```text
                    Authentication Server
                       (Identity Provider)
                              │
                         User Login
                              │
                              ↓
                   ASP.NET Core MVC App
                      (Client App 1)
                              │
                       Access Token
                              │
                              ↓
                   Resource Server API
```

### 1. Configure OpenID Connect

Install:

```bash
dotnet add package Microsoft.AspNetCore.Authentication.OpenIdConnect
```

Configure authentication:

```csharp
builder.Services
    .AddAuthentication(options =>
    {
        options.DefaultScheme = CookieAuthenticationDefaults.AuthenticationScheme;
        options.DefaultChallengeScheme = OpenIdConnectDefaults.AuthenticationScheme;
    })
    .AddCookie()
    .AddOpenIdConnect(options =>
    {
        options.Authority = "https://your-identity-provider";
        options.ClientId = "client-app-one";
        options.ClientSecret = "client-secret";
        options.ResponseType = "code";
        options.SaveTokens = true;
    });
```

Enable middleware:

```csharp
app.UseAuthentication();
app.UseAuthorization();
```

### 2. Protect MVC Controller

```csharp
[Authorize]
public class HomeController : Controller
{
    public IActionResult Index()
    {
        return View();
    }
}
```

When an unauthenticated user accesses this controller:

```text
MVC App
   ↓
Redirect to Identity Provider
   ↓
User Login
   ↓
Authentication successful
   ↓
Redirect back to MVC App
   ↓
Authenticated
```

### 3. SSO Benefit

If the user later opens **Client Application Two**:

```text
Client App 1 ──┐
               ↓
        Identity Provider
               ↑
Client App 2 ──┘
```

Because the user already has an authenticated session with the Identity Provider, **Client App 2 can authenticate the user without requiring another login**.

### Interview Answer

> **Client Application One is an ASP.NET Core MVC application configured with OpenID Connect. When authentication is required, it redirects the user to the central Identity Provider. After successful authentication, the Identity Provider returns an authorization code, which the MVC application exchanges for tokens and establishes its local session. Because authentication is centralized, the same user session can be used by other client applications, providing SSO.**
