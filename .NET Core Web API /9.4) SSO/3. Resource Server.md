# Resource Server using ASP.NET Core Web API

In an **SSO architecture**, the **Resource Server** is the API that protects business data and resources. It **does not authenticate the user directly**. Instead, it validates the access token issued by the **Authentication Server / Identity Provider**.

### Architecture

```text
                 Authentication Server
                    (Identity Provider)
                           │
                     User Login
                           │
                     Access Token
                           ↓
                      Client App
                           │
                 Authorization: Bearer
                           │
                           ↓
                 ASP.NET Core Web API
                    (Resource Server)
                           │
                  Validate Token
                           ↓
                  Access Resources
```

### Implementation

Install JWT authentication:

```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
```

Configure the API:

```csharp
builder.Services
    .AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.Authority = "https://your-identity-provider";
        options.Audience = "your-api";
    });

builder.Services.AddAuthorization();
```

Middleware:

```csharp
app.UseAuthentication();
app.UseAuthorization();
```

Protect an endpoint:

```csharp
[Authorize]
[HttpGet("patients")]
public IActionResult GetPatients()
{
    return Ok("Protected patient data");
}
```

### Request Flow

```text
Client
  ↓
Access Token
  ↓
Resource Server
  ↓
Validate token
  ├── Invalid → 401 Unauthorized
  └── Valid
       ↓
   Check authorization
       ↓
   Controller
       ↓
   Protected resource
```

### Key Point

The Resource Server is responsible for:

* **Validating access tokens**
* **Checking claims/roles/scopes**
* **Authorizing API requests**
* **Returning protected resources**

> **Interview answer:**
> A Resource Server is an ASP.NET Core Web API that protects business resources. In an SSO architecture, it trusts the Authentication Server/Identity Provider and validates the access token sent by the client. If the token is valid and the required scope or role is present, the API allows access to the requested resource.
