# HTTP PATCH Method in ASP.NET Core Web API

The **HTTP PATCH** method is used to **partially update an existing resource**.

Unlike `PUT`, PATCH updates **only the specified properties**, rather than replacing the entire resource.

### Basic Example

```csharp
[HttpPatch("{id}")]
public IActionResult UpdateProduct(int id, Product product)
{
    var existing = _context.Products.Find(id);

    if (existing == null)
        return NotFound();

    existing.Price = product.Price;

    _context.SaveChanges();

    return NoContent();
}
```

### Example Request

```http
PATCH /api/products/10
Content-Type: application/json

{
    "price": 60000
}
```

Only the **Price** is updated; other properties remain unchanged.

### Important Points

* **PATCH = Partial Update**
* Updates only selected properties.
* Useful when you don't want to send the complete resource.
* Unlike PUT, PATCH is **not necessarily idempotent**.
* Common response: `204 No Content`

**Key difference:**

`PUT` → Replace/update the complete resource
`PATCH` → Update only specific fields
