# HTTP HEAD Method in ASP.NET Core Web API

The **HTTP HEAD** method is used to retrieve the **same headers as a GET request, but without the response body**.

### Basic Example

```csharp
[HttpHead("{id}")]
public IActionResult CheckProduct(int id)
{
    var product = _context.Products.Find(id);

    if (product == null)
        return NotFound();

    return Ok();
}
```

### Example Request

```http
HEAD /api/products/10
```

### Important Points

* **HEAD = Get headers without body**
* Useful for checking whether a resource **exists**.
* Used for checking **metadata**, `Content-Length`, caching information, etc.
* Server should **not return a response body**.
* Usually returns the same status that the corresponding GET would return.

**Key difference:**

`GET` → Headers + Response Body
`HEAD` → Headers only
