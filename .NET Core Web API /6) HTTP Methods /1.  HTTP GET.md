# HTTP GET Method in ASP.NET Core Web API

The **HTTP GET** method is used to **retrieve/read data** from the server. It should not modify database data.

### Basic Example

```csharp
[HttpGet]
public IActionResult GetProducts()
{
    var products = _context.Products.ToList();
    return Ok(products);
}
```

### Common GET Variations

| Type            | Example                             | Purpose                |
| --------------- | ----------------------------------- | ---------------------- |
| Get all         | `GET /api/products`                 | Retrieve all products  |
| Get by ID       | `GET /api/products/10`              | Retrieve one product   |
| Query string    | `GET /api/products?category=mobile` | Filter/search data     |
| Route parameter | `GET /api/products/10`              | Pass value through URL |

### GET with Route Parameter

```csharp
[HttpGet("{id}")]
public IActionResult GetProduct(int id)
{
    var product = _context.Products.Find(id);

    if (product == null)
        return NotFound();

    return Ok(product);
}
```

### Important Points

* **GET = Read/Retrieve data**
* Data is usually passed through **Route** or **Query String**.
* Request body is generally **not used** with GET.
* Common responses:

  * `200 OK` → Data retrieved successfully
  * `404 Not Found` → Resource doesn't exist
  * `400 Bad Request` → Invalid request
* GET should be **safe and idempotent**—repeating the same GET should not change server state.
