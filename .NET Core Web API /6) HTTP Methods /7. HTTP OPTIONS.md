# HTTP OPTIONS Method in ASP.NET Core Web API

The **HTTP OPTIONS** method is used to determine **which HTTP methods and communication options are supported** by an API/resource.

### Example

```csharp
[HttpOptions]
public IActionResult Options()
{
    Response.Headers.Append("Allow", "GET, POST, PUT, DELETE");
    return Ok();
}
```

### Example Request

```http
OPTIONS /api/products
```

### Response

```http
Allow: GET, POST, PUT, DELETE
```

### Important Points

* **OPTIONS = Discover supported operations**
* Commonly used with **CORS (Cross-Origin Resource Sharing)**.
* Browsers may send a **preflight OPTIONS request** before certain cross-origin requests.
* It generally **does not modify data**.
* The `Allow` header can indicate supported HTTP methods.

**In short:**
`OPTIONS` → *"What operations are allowed on this resource?"*
