# HTTP PUT Method in ASP.NET Core Web API

The **HTTP PUT** method is used to **update an existing resource**, typically replacing the entire resource.

### Basic Example

```csharp
[HttpPut("{id}")]
public IActionResult UpdateProduct(int id, Product product)
{
    if (id != product.Id)
        return BadRequest();

    _context.Products.Update(product);
    _context.SaveChanges();

    return NoContent();
}
```

### Example Request

```http
PUT /api/products/10
Content-Type: application/json

{
    "id": 10,
    "name": "Laptop",
    "price": 60000
}
```

### Important Points

* **PUT = Update/Replace an existing resource**
* Data is usually sent in the **request body**.
* Resource is commonly identified using a **Route parameter**.
* PUT is **idempotent** — sending the same request multiple times produces the same result.
* Common responses:

  * `204 No Content` → Successfully updated
  * `200 OK` → Updated and returning data
  * `400 Bad Request` → Invalid request
  * `404 Not Found` → Resource doesn't exist

**Key difference:**
`POST` → Create new resource
`PUT` → Update/replace existing resource
