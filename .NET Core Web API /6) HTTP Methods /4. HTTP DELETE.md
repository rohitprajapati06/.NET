# HTTP DELETE Method in ASP.NET Core Web API

The **HTTP DELETE** method is used to **remove an existing resource** from the server/database.

### Basic Example

```csharp
[HttpDelete("{id}")]
public IActionResult DeleteProduct(int id)
{
    var product = _context.Products.Find(id);

    if (product == null)
        return NotFound();

    _context.Products.Remove(product);
    _context.SaveChanges();

    return NoContent();
}
```

### Example Request

```http
DELETE /api/products/10
```

### Important Points

* **DELETE = Remove/Delete data**
* Resource is commonly identified using a **Route parameter**.
* Usually doesn't require a request body.
* DELETE is **idempotent** — repeating the same delete should leave the resource deleted.
* Common responses:

  * `204 No Content` → Successfully deleted
  * `404 Not Found` → Resource doesn't exist
  * `400 Bad Request` → Invalid request
