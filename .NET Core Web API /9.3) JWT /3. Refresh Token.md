# Refresh Token in ASP.NET Core Web API using JWT Authentication

A **Refresh Token** is a long-lived token used to obtain a **new JWT access token** after the current JWT expires, without requiring the user to log in again.

### Why do we need a Refresh Token?

JWT access tokens should generally have a **short lifetime** for security.

For example:

```text
Access Token → Expires in 15 minutes
Refresh Token → Expires in 7 days
```

When the access token expires:

```text
Client
   │
   │ Access Token
   ▼
API
   │
   └── Token expired ❌
   
Client
   │
   │ Refresh Token
   ▼
API
   │
   ▼
New Access Token ✅
```

### Typical Flow

```text
1. User Login
      ↓
2. API validates credentials
      ↓
3. API generates:
      ├── Access Token (JWT)
      └── Refresh Token
      ↓
4. Client stores tokens

After JWT expires:

5. Client → /refresh-token
             Refresh Token
      ↓
6. API validates Refresh Token
      ↓
7. API generates new Access Token
      ↓
8. Client continues making API calls
```

### Access Token vs Refresh Token

| Access Token           | Refresh Token                       |
| ---------------------- | ----------------------------------- |
| Short-lived            | Long-lived                          |
| Used to access APIs    | Used to obtain a new access token   |
| JWT                    | Usually a random secure string      |
| Sent with API requests | Sent only to token-refresh endpoint |
| Expires quickly        | Expires after days/weeks            |

### Example Model

```csharp
public class RefreshToken
{
    public int Id { get; set; }
    public string Token { get; set; }
    public DateTime ExpiresAt { get; set; }
    public bool IsRevoked { get; set; }
    public int UserId { get; set; }
}
```

The refresh token should normally be **stored server-side**, commonly in a database, so it can be revoked.

### Refresh Endpoint

```csharp
[HttpPost("refresh-token")]
public IActionResult RefreshToken(string refreshToken)
{
    var token = db.RefreshTokens
                  .FirstOrDefault(x => x.Token == refreshToken);

    if (token == null ||
        token.IsRevoked ||
        token.ExpiresAt <= DateTime.UtcNow)
    {
        return Unauthorized();
    }

    var newAccessToken = GenerateJwtToken(token.UserId);

    return Ok(new
    {
        accessToken = newAccessToken
    });
}
```

### Important Security Practice: Token Rotation

A stronger implementation **rotates refresh tokens**:

```text
Old Refresh Token
       ↓
     Used
       ↓
    Revoked
       ↓
New Access Token + New Refresh Token
```

This reduces the impact if a refresh token is stolen.

### Interview Answer

> **"A refresh token is a long-lived credential used to obtain a new short-lived JWT access token when the existing access token expires. Instead of asking the user to log in again, the client sends the refresh token to a refresh endpoint. The API validates it, and if valid, issues a new access token. Refresh tokens should be securely stored, validated, expired and preferably rotated and revocable."**
