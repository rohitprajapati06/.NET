# JWT Authentication in ASP.NET Core Web API

**JWT (JSON Web Token)** is a token-based authentication mechanism used to securely authenticate users in ASP.NET Core Web APIs.

### How JWT Authentication Works

```text
Client → Login API → Validate Username/Password
                    ↓
                 Generate JWT
                    ↓
Client ← JWT Token ← API

Client → API + JWT Token → JWT Middleware
                            ↓
                       Validate Token
                            ↓
                       Controller
```

### 1. Install JWT Package

```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
```

### 2. Configure JWT Authentication

In `Program.cs`:

```csharp
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,

            ValidIssuer = "MyApi",
            ValidAudience = "MyClient",

            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes("my-secret-key-12345"))
        };
    });

builder.Services.AddAuthorization();
```

Then add middleware:

```csharp
app.UseAuthentication();
app.UseAuthorization();
```

**Order is important:** `UseAuthentication()` must come before `UseAuthorization()`.

### 3. Generate JWT During Login

```csharp
var claims = new[]
{
    new Claim(ClaimTypes.Name, user.Username),
    new Claim(ClaimTypes.Role, user.Role)
};

var key = new SymmetricSecurityKey(
    Encoding.UTF8.GetBytes("my-secret-key-12345"));

var credentials = new SigningCredentials(
    key, SecurityAlgorithms.HmacSha256);

var token = new JwtSecurityToken(
    issuer: "MyApi",
    audience: "MyClient",
    claims: claims,
    expires: DateTime.UtcNow.AddHours(1),
    signingCredentials: credentials);

var jwt = new JwtSecurityTokenHandler().WriteToken(token);

return Ok(new { token = jwt });
```

### 4. Protect an API

Use `[Authorize]`:

```csharp
[Authorize]
[HttpGet]
public IActionResult GetUsers()
{
    return Ok("Authenticated user");
}
```

The client sends the token in the HTTP header:

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

### 5. Role-Based Authorization

If the JWT contains:

```csharp
new Claim(ClaimTypes.Role, "Admin")
```

You can restrict an endpoint:

```csharp
[Authorize(Roles = "Admin")]
[HttpDelete("{id}")]
public IActionResult DeleteUser(int id)
{
    return Ok("User deleted");
}
```

### Important JWT Parts

A JWT has **three parts**:

```text
Header.Payload.Signature
```

For example:

```text
xxxxx.yyyyy.zzzzz
```

* **Header** → Algorithm and token type
* **Payload** → Claims such as username, role, expiration
* **Signature** → Ensures the token hasn't been tampered with

### JWT vs Session Authentication

| JWT                         | Session                        |
| --------------------------- | ------------------------------ |
| Stateless                   | Usually server-side state      |
| Token stored by client      | Session stored on server       |
| Good for Web APIs           | Common in traditional web apps |
| Easy to use across services | Requires session management    |

**Interview answer:**

> "JWT authentication is a stateless, token-based authentication mechanism. After successful login, the server generates a signed JWT containing claims and sends it to the client. The client sends the token as a Bearer token with subsequent requests. ASP.NET Core's JWT middleware validates the token, and `[Authorize]` is used to protect APIs."
