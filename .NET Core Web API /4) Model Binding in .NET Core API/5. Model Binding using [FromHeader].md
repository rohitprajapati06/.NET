## `[FromHeader]` in ASP.NET Core

`[FromHeader]` is a **model binding attribute** used to get values from the **HTTP request headers** and bind them to an action parameter.

### Simple Example

Request:

```http
GET /api/patients
X-Correlation-Id: abc123
```

Controller:

```csharp
[HttpGet]
public IActionResult GetPatients(
    [FromHeader(Name = "X-Correlation-Id")] string correlationId)
{
    return Ok(correlationId);
}
```

ASP.NET Core automatically binds:

```text
Header
X-Correlation-Id: abc123
        ↓
[FromHeader]
        ↓
correlationId = "abc123"
```

### Without specifying the name

If the parameter name matches the header name:

```csharp
public IActionResult GetPatients(
    [FromHeader] string XCorrelationId)
{
}
```

However, explicitly specifying the header name is generally clearer:

```csharp
[FromHeader(Name = "X-Correlation-Id")]
string correlationId
```

### Common use cases

`[FromHeader]` can be used for:

* Correlation ID
* Tenant ID
* API version
* Custom client headers
* Request metadata

Example:

```http
X-Tenant-Id: 100
X-Correlation-Id: abc123
```

```csharp
public IActionResult Get(
    [FromHeader(Name = "X-Tenant-Id")] int tenantId,
    [FromHeader(Name = "X-Correlation-Id")] string correlationId)
{
}
```

### `[FromHeader]` vs `[FromQuery]`

| Attribute      | Source       | Example               |
| -------------- | ------------ | --------------------- |
| `[FromHeader]` | HTTP headers | `X-Tenant-Id: 100`    |
| `[FromQuery]`  | Query string | `?tenantId=100`       |
| `[FromRoute]`  | URL route    | `/patients/100`       |
| `[FromBody]`   | Request body | `{ "name": "Rohit" }` |

### Interview definition

> `[FromHeader]` tells ASP.NET Core to bind an action parameter or model property from an HTTP request header.

**Key point:** `[FromHeader]` = **data comes from HTTP headers.**
