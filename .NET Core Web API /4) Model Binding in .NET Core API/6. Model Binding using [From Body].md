## `[FromBody]` in ASP.NET Core Web API

`[FromBody]` is a **model binding attribute** that tells ASP.NET Core to get the data from the **HTTP request body**.

It is most commonly used with **JSON data** in `POST`, `PUT`, and `PATCH` requests.

### Simple Example

Request:

```http
POST /api/patients
Content-Type: application/json
```

```json
{
    "name": "Rohit",
    "age": 25
}
```

Model:

```csharp
public class CreatePatientRequest
{
    public string Name { get; set; }
    public int Age { get; set; }
}
```

Controller:

```csharp
[HttpPost]
public IActionResult CreatePatient(
    [FromBody] CreatePatientRequest request)
{
    return Ok(request);
}
```

ASP.NET Core converts:

```text
JSON Request Body
       ↓
JSON Deserialization
       ↓
CreatePatientRequest
       ↓
Controller
```

So:

```csharp
request.Name // "Rohit"
request.Age  // 25
```

### Why `[FromBody]`?

It tells ASP.NET Core **where the data should come from**.

```text
[FromQuery]  → ?name=Rohit
[FromRoute]  → /patients/101
[FromHeader] → X-Tenant-Id: 10
[FromBody]   → JSON/XML request body
[FromForm]   → form-data
```

### Important: `[FromBody]` and JSON

The request normally has:

```http
Content-Type: application/json
```

ASP.NET Core uses an **input formatter** (typically `System.Text.Json`) to deserialize the JSON into your C# model.

### `[FromBody]` with DTO — Recommended

For example:

```csharp
public class CreateAppointmentRequest
{
    public int DoctorId { get; set; }
    public int PatientId { get; set; }
    public DateTime AppointmentDate { get; set; }
}
```

```csharp
[HttpPost]
public IActionResult CreateAppointment(
    [FromBody] CreateAppointmentRequest request)
{
    // Business/application logic
}
```

This is preferable to binding directly to your database entity.

### Important interview point

Generally, an action should have **only one `[FromBody]` parameter**, because the request body is read as a single stream.

❌ Avoid:

```csharp
public IActionResult Create(
    [FromBody] Patient patient,
    [FromBody] Appointment appointment)
```

✅ Instead, use one DTO:

```csharp
public class CreateAppointmentRequest
{
    public PatientRequest Patient { get; set; }
    public AppointmentRequest Appointment { get; set; }
}
```

### Interview definition

> `[FromBody]` tells ASP.NET Core to bind an action parameter from the HTTP request body, typically by deserializing JSON into a C# model or DTO.

**Key point:** `[FromBody]` = **data comes from the request body.**
