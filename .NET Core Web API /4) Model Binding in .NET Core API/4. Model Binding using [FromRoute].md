## `[FromRoute]` in ASP.NET Core

`[FromRoute]` is a **model binding attribute** used to get values from the **route/URL path** and bind them to an action parameter.

### Simple Example

Request:

```http
GET /api/patients/101
```

Controller:

```csharp
[HttpGet("{id}")]
public IActionResult GetPatient([FromRoute] int id)
{
    return Ok(id);
}
```

ASP.NET Core automatically binds:

```text
URL: /api/patients/101
              ↓
[FromRoute] int id
              ↓
id = 101
```

---

### Multiple Route Parameters

```http
GET /api/hospitals/10/patients/101
```

```csharp
[HttpGet("{hospitalId}/patients/{patientId}")]
public IActionResult GetPatient(
    [FromRoute] int hospitalId,
    [FromRoute] int patientId)
{
    // hospitalId = 10
    // patientId = 101
}
```

The parameter names should match the route parameter names.

---

### `[FromRoute(Name = "...")]`

If the names don't match:

```csharp
[HttpGet("{patientId}")]
public IActionResult GetPatient(
    [FromRoute(Name = "patientId")] int id)
{
}
```

Here:

```text
Route parameter → patientId
C# parameter    → id
```

---

### `[FromRoute]` vs `[FromQuery]`

| `[FromRoute]`                 | `[FromQuery]`                      |
| ----------------------------- | ---------------------------------- |
| Gets value from URL path      | Gets value from query string       |
| `/patients/101`               | `/patients?id=101`                 |
| Usually identifies a resource | Usually filters/configures request |

Example:

```text
/api/patients/101
             ↑
          FromRoute
```

```text
/api/patients?id=101
              ↑
           FromQuery
```

### Interview definition

> `[FromRoute]` tells ASP.NET Core to bind an action parameter or model property from a value in the URL route template.

**Key point:** `[FromRoute]` = **value is part of the URL path**.
