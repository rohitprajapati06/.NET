# FluentValidation Async Validators in ASP.NET Core Web API

**Async validators** are used when validation requires an **asynchronous operation**, such as checking a database, calling an external API, or verifying whether a value already exists.

### 1. Example: Check Email Exists in Database

```csharp
public class EmployeeValidator : AbstractValidator<Employee>
{
    private readonly IEmployeeRepository _repository;

    public EmployeeValidator(IEmployeeRepository repository)
    {
        _repository = repository;

        RuleFor(x => x.Email)
            .MustAsync(async (email, cancellation) =>
                !await _repository.EmailExistsAsync(email))
            .WithMessage("Email already exists.");
    }
}
```

Here:

* `MustAsync()` → performs asynchronous custom validation.
* `EmailExistsAsync()` → checks the database asynchronously.
* `cancellation` → allows the operation to be cancelled.

### 2. Example Repository

```csharp
public async Task<bool> EmailExistsAsync(string email)
{
    return await _context.Employees
        .AnyAsync(x => x.Email == email);
}
```

### 3. Important: Validate Asynchronously

```csharp
var result = await validator.ValidateAsync(employee);

if (!result.IsValid)
{
    return BadRequest(result.Errors);
}
```

### `Must()` vs `MustAsync()`

| `Must()`                   | `MustAsync()`                 |
| -------------------------- | ----------------------------- |
| Synchronous validation     | Asynchronous validation       |
| No `await`                 | Supports `await`              |
| Simple calculations/checks | Database/API/file operations  |
| `RuleFor(...).Must(...)`   | `RuleFor(...).MustAsync(...)` |

### Another useful async validator

```csharp
RuleFor(x => x.Username)
    .MustAsync(async (username, cancellation) =>
        await _repository.IsUsernameAvailableAsync(username))
    .WithMessage("Username is already taken.");
```

**Key point:** Use `MustAsync()` whenever your validation rule needs an asynchronous operation. Avoid making synchronous database calls just for validation.
