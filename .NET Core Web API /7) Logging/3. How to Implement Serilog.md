# How to Implement Serilog in ASP.NET Core Web API

**Serilog** is a third-party structured logging library for .NET. It provides better logging than the default `ILogger`, especially for **file logging, structured logs, filtering, and centralized logging**.

### 1. Install NuGet Packages

Install:

```text
Serilog.AspNetCore
Serilog.Sinks.Console
Serilog.Sinks.File
```

---

### 2. Configure Serilog in `Program.cs`

```csharp
using Serilog;

var builder = WebApplication.CreateBuilder(args);

Log.Logger = new LoggerConfiguration()
    .MinimumLevel.Information()
    .WriteTo.Console()
    .WriteTo.File("Logs/log.txt", rollingInterval: RollingInterval.Day)
    .CreateLogger();

builder.Host.UseSerilog();

builder.Services.AddControllers();

var app = builder.Build();

app.MapControllers();

app.Run();
```

Now logs are written to:

```text
Console
   +
Logs/log-20260909.txt
```

---

### 3. Use `ILogger<T>` in Controller

You still use the normal ASP.NET Core `ILogger`:

```csharp
public class PatientController : ControllerBase
{
    private readonly ILogger<PatientController> _logger;

    public PatientController(ILogger<PatientController> logger)
    {
        _logger = logger;
    }

    [HttpGet]
    public IActionResult GetPatients()
    {
        _logger.LogInformation("Fetching patients");

        return Ok();
    }
}
```

Serilog automatically receives these logs.

---

### 4. Structured Logging

Instead of:

```csharp
_logger.LogInformation("Patient ID is " + patientId);
```

Prefer:

```csharp
_logger.LogInformation(
    "Patient {PatientId} retrieved successfully",
    patientId);
```

`PatientId` becomes a **structured property**, which makes logs easier to search and analyze.

---

### 5. Logging Exceptions

```csharp
try
{
    // database operation
}
catch (Exception ex)
{
    _logger.LogError(ex,
        "Error while retrieving patient {PatientId}",
        patientId);

    throw;
}
```

Serilog records both the **message and exception details**.

### Typical Enterprise Flow

```text
Controller / Service
        ↓
    ILogger<T>
        ↓
     Serilog
        ↓
 ┌──────┼─────────┐
 ↓      ↓         ↓
Console File   Application Insights
              / Seq / Elasticsearch
```

**Key point:** Serilog doesn't replace `ILogger<T>`. It acts as the **logging provider/backend**, while your application continues using the standard `ILogger<T>` abstraction.
