# Media Type Versioning in ASP.NET Core Web API

**Media Type Versioning** means the client specifies the API version through the HTTP `Accept` header rather than the URL or query string.

For example:

```http
GET /api/products
Accept: application/json;v=1.0
```

or:

```http
GET /api/products
Accept: application/json;v=2.0
```

The API uses the `Accept` header to determine which version should be executed.

---

## 1. Install Package

```bash
dotnet add package Asp.Versioning.Mvc
```

---

## 2. Configure Versioning

In `Program.cs`:

```csharp
using Asp.Versioning;

builder.Services.AddApiVersioning(options =>
{
    options.DefaultApiVersion = new ApiVersion(1, 0);

    options.AssumeDefaultVersionWhenUnspecified = true;

    options.ReportApiVersions = true;

    options.ApiVersionReader =
        new MediaTypeApiVersionReader("v");
});
```

The important part is:

```csharp
new MediaTypeApiVersionReader("v")
```

It tells ASP.NET Core to look for the version in the media type parameter `v`.

---

## 3. Create Versioned Controller

```csharp
[ApiController]
[Route("api/products")]
[ApiVersion(1.0)]
[ApiVersion(2.0)]
public class ProductsController : ControllerBase
{
    [HttpGet]
    [MapToApiVersion(1.0)]
    public IActionResult GetV1()
    {
        return Ok(new
        {
            Id = 1,
            Name = "Laptop"
        });
    }

    [HttpGet]
    [MapToApiVersion(2.0)]
    public IActionResult GetV2()
    {
        return Ok(new
        {
            ProductId = 1,
            ProductName = "Laptop",
            Price = 50000
        });
    }
}
```

---

## 4. Calling V1

Request:

```http
GET /api/products
Accept: application/json;v=1.0
```

Response:

```json
{
  "id": 1,
  "name": "Laptop"
}
```

---

## 5. Calling V2

Request:

```http
GET /api/products
Accept: application/json;v=2.0
```

Response:

```json
{
  "productId": 1,
  "productName": "Laptop",
  "price": 50000
}
```

The URL remains the same:

```text
/api/products
```

Only the `Accept` header changes.

---

## How It Works

```text
Client
   │
   │ GET /api/products
   │ Accept: application/json;v=2.0
   ↓
MediaTypeApiVersionReader
   │
   │ Version = 2.0
   ↓
[MapToApiVersion(2.0)]
   ↓
GetV2()
   ↓
Response
```

---

## Media Type vs Query String

| Approach     | Example                          |
| ------------ | -------------------------------- |
| Query String | `/api/products?api-version=2.0`  |
| Media Type   | `Accept: application/json;v=2.0` |
| URL Segment  | `/api/v2/products`               |
| Header       | `api-version: 2.0`               |

### Interview Answer

> **Media Type Versioning** is an API versioning technique where the client specifies the API version through the HTTP `Accept` header. In ASP.NET Core, `MediaTypeApiVersionReader` reads the version from the media type, allowing multiple API versions to use the same URL.
