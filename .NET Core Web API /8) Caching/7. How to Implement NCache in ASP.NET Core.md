# How to Implement NCache in ASP.NET Core Web API

**NCache** is a distributed in-memory cache that can be used with ASP.NET Core through `IDistributedCache`.

### 1. Install NCache Package

```bash
dotnet add package Alachisoft.NCache.AspNetCore
```

### 2. Configure NCache

In `Program.cs`:

```csharp
builder.Services.AddNCacheDistributedCache(options =>
{
    options.CacheName = "myCache";
    options.EnableLogs = true;
    options.ExceptionsEnabled = true;
});
```

Here, `"myCache"` is the NCache cache that you have created/configured in NCache.

### 3. Inject `IDistributedCache`

```csharp
private readonly IDistributedCache _cache;

public ProductController(IDistributedCache cache)
{
    _cache = cache;
}
```

### 4. Store and Retrieve Data

```csharp
[HttpGet]
public async Task<IActionResult> GetProducts()
{
    string key = "products";

    var cachedData = await _cache.GetStringAsync(key);

    if (cachedData != null)
    {
        return Ok(JsonSerializer.Deserialize<List<Product>>(cachedData));
    }

    var products = await _context.Products.ToListAsync();

    await _cache.SetStringAsync(
        key,
        JsonSerializer.Serialize(products),
        new DistributedCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(10)
        });

    return Ok(products);
}
```

### How it works

```text
Client
  ↓
Web API
  ↓
NCache
  ↓
Cache Hit? ── Yes ──→ Return Data
  │
  No
  ↓
Database
  ↓
Store in NCache
  ↓
Return Data
```

### Important Configuration

Before running the application, you need an **NCache server/cache cluster** configured and available to the API.

For example:

```text
        ASP.NET Core API
               ↓
        NCache Client
               ↓
      ┌────────┴────────┐
 NCache Server 1    NCache Server 2
      └────────┬────────┘
          NCache Cluster
```

### NCache vs Redis

Both can implement `IDistributedCache`.

| NCache                         | Redis                                |
| ------------------------------ | ------------------------------------ |
| .NET-focused caching platform  | General-purpose in-memory data store |
| Rich .NET-specific features    | Broad ecosystem                      |
| Supports clustering/topologies | Supports clustering/replication      |
| Provides distributed caching   | Provides distributed caching         |

**Interview point:** In ASP.NET Core, NCache can be integrated as an `IDistributedCache` implementation, allowing your application to use distributed caching without tightly coupling application code to NCache APIs.
