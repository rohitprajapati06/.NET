# NCache Cluster and Its Types in Distributed Caching

**NCache** is a distributed in-memory caching solution for .NET applications. A **cluster** is a group of NCache servers that work together to provide a shared, scalable cache.

### NCache Cluster

Instead of keeping cache data on a single server:

```text
        Application
             ↓
       NCache Cluster
      ┌──────┼──────┐
   Server1 Server2 Server3
```

Multiple NCache servers work together, providing **high availability, scalability, and load distribution**.

### Types of NCache Clustering

| Type                        | Description                                                                                                                        |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Mirrored Cache**          | Two-node cluster where one node is active and the other maintains a replica. Provides backup/failover.                             |
| **Replicated Cache**        | Every cache item is replicated to **all nodes**. Provides high availability but uses more memory.                                  |
| **Partitioned Cache**       | Cache data is divided (partitioned) among nodes. Each node stores a portion of the data.                                           |
| **Partition-Replica Cache** | Data is partitioned across nodes, and each partition has a replica on another node. Provides both scalability and fault tolerance. |

### Quick Comparison

| Type                  | Data Distribution    | Backup | Scalability |
| --------------------- | -------------------- | ------ | ----------- |
| **Mirrored**          | Active + mirror      | ✅      | Low         |
| **Replicated**        | All nodes            | ✅      | Medium      |
| **Partitioned**       | Divided across nodes | ❌      | High        |
| **Partition-Replica** | Divided + replicas   | ✅      | **High**    |

**Interview point:** **Partition-Replica Cache** is particularly useful for large-scale applications because it combines the scalability of partitioning with the fault tolerance of replication.
