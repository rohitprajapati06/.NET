# Redis Cache in ASP.NET Core Web API

**Redis** is a distributed, in-memory key-value store commonly used for caching. Unlike `IMemoryCache`, Redis allows **multiple API instances to share the same cache**.

### 1. Install Redis Package

Install:

```bash
dotnet add package Microsoft.Extensions.Caching.StackExchangeRedis
```

### 2. Configure Redis

In `Program.cs`:

```csharp
builder.Services.AddStackExchangeRedisCache(options =>
{
    options.Configuration = "localhost:6379";
    options.InstanceName = "MyApp_";
});
```

### 3. Inject `IDistributedCache`

```csharp
private readonly IDistributedCache _cache;

public ProductController(IDistributedCache cache)
{
    _cache = cache;
}
```

### 4. Store and Retrieve Data

```csharp
[HttpGet]
public async Task<IActionResult> GetProducts()
{
    var cacheKey = "products";

    var cachedData = await _cache.GetStringAsync(cacheKey);

    if (cachedData != null)
    {
        var products = JsonSerializer.Deserialize<List<Product>>(cachedData);
        return Ok(products);
    }

    var data = await _context.Products.ToListAsync();

    await _cache.SetStringAsync(
        cacheKey,
        JsonSerializer.Serialize(data),
        new DistributedCacheEntryOptions
        {
            AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(10)
        });

    return Ok(data);
}
```

### How it works

```text
Request
   ↓
Redis Cache
   ↓
Found? ── Yes ──→ Return Data
   │
   No
   ↓
Database
   ↓
Store in Redis
   ↓
Return Data
```

### Redis vs In-Memory Cache

| Feature                  | IMemoryCache         | Redis                       |
| ------------------------ | -------------------- | --------------------------- |
| Storage                  | Application RAM      | Redis server                |
| Multiple API servers     | ❌                    | ✅                           |
| Shared cache             | ❌                    | ✅                           |
| Distributed applications | Not ideal            | ✅                           |
| Persistence options      | ❌                    | ✅                           |
| Common use               | Single-instance apps | Production/distributed apps |

**Interview point:** Use `IMemoryCache` for local, single-instance caching. Use **Redis with `IDistributedCache`** when cache needs to be shared across multiple API instances.
